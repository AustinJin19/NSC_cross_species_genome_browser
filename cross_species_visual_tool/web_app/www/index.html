Gene activity uses unweighted integrated bigWig signal, not fragment counts or RNA expression. TSS windows use the outer gene-locus TSS and are clipped at chromosome ends; nearby genes can share signal. Activity scale selects raw median activity or log₁₀ of the species median. Zero and negative values are excluded in log mode; no pseudocount is added. Per-sample values remain untransformed. The fit uses one median per species in CPM·bp. Human and macaque are excluded from the fit; their values remain visible in the table. Human uses source-scaled·bp. Symbol matches are not verified orthologs. Gene-body correlations adjust only for log₁₀(annotated gene length), without body mass; TSS-window correlations are unadjusted. Source normalization and phylogeny can affect these exploratory associations. New species are quantified on demand; MLS and body mass use the supplied species table. Lower-bound MLS entries (>20) are shown but excluded from ordinary correlations.

Regulatory activity by species

SpeciesMedian peak countMLS (years)Body mass (g)Fit status

Peak count counts overlapping ATAC peaks. CPM signal in peaks sums bigWig signal × base pairs only inside each sample’s peak regions intersecting the selected TSS window (CPM·bp). Overlapping peaks are merged so each base counts once; signal outside peaks is excluded. Signal uses the source normalization, with no distance weighting or division by peak length. Unrepresented bigWig bases contribute zero. Both measurements use the median across samples within each species. Windows extend 20 kb, 50 kb, 100 kb, 200 kb or 500 kb on each side of the TSS and are clipped at chromosome ends. For multiple loci, the locus with the highest species-median value for the selected measurement is used. Missing or incompatible peak files are unavailable, not zero. Pearson correlation and the linear fit use the selected scales, without gene-length or body-mass adjustment. Human and macaque are excluded; bowhead can be included using the checkbox. Human signal retains source-scaled·bp units in the table. Log mode excludes nonpositive counts without a pseudocount. P-values are nominal, with no phylogenetic or multiple-testing correction. Peak calling and sequencing depth affect counts; nearby genes can share peaks.
